# Quickstart: Frontend Chat Integration

This guide explains how to run the Docusaurus frontend locally to test the chat widget.

1.  **Navigate to the textbook directory**:
    ```bash
    cd ros2-textbook
    ```

2.  **Install dependencies**:
    ```bash
    npm install
    ```

3.  **Run the development server**:
    ```bash
    npm start
    ```

The Docusaurus site will be available at `http://localhost:3000`. The chat widget will be visible on all pages.
